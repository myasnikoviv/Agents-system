# Retrospective Report Schema v1

## Required Sections
1. What went well
2. What failed
3. Why it failed (root cause)
4. Which role failed
5. Which instruction/skill/checklist was insufficient
6. What should be updated
7. Whether new skill/checklist is required
8. Final recommendation (apply now / queue / reject)

## Header Template
```yaml
id: RETRO-<date>-<seq>
source_task: <ticket id>
pipeline: <pipeline name>
created_by: Knowledge Curator
reviewed_by: PM Orchestrator
status: draft|review|approved
```
