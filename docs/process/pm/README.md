# PM Process Artifacts

- `team-issue-register.md` - recurring execution problems by role and preventive controls.
- `sprint-efficiency-log.md` - sprint-level efficiency metrics, bottlenecks, and process actions.
- Ticket brief quality gate uses: `docs/process/tickets/TICKET-BRIEF-TEMPLATE.md`.
- `ticket-quality-checklist.md` - mandatory PM gate before moving ticket to `In Progress`.
- `handoff-protocol.md` - required reassignment/comment/artifact protocol between roles.
- `git-preflight-log.md` - pre-implementation branch/scope/commit/rollback decisions.
- `PROGRESS-ROUTER-CONTRACT.md` - deterministic continuation gate (`continue/продовжуємо`).
- `VERIFICATION-GATE-CONTRACT.md` - mandatory CLI+UI verification gate before Done.
- `audits/` - daily PM audit reports generated by `scripts/plane/pm_daily_audit.sh`.
- `VERIFICATION-DEBT-AUDIT-CONTRACT.md` - cross-phase verification debt check before sprint closure.

## Progress Router Routine (Mandatory on Continuation)
1. Run: `bash scripts/pm/progress_router.sh <ticket-or-thread>`
2. Read `next_action` and execute only that path.
3. Update the same pipeline-state card right after stage movement.

## Daily PM Audit Routine
1. Run: `scripts/plane/pm_daily_audit.sh`
2. Review critical findings first:
   - missing descriptions
   - in-progress without assignee
   - in-progress without cycle
3. Review warnings:
   - missing handoff comments
   - missing required sections in ticket descriptions
4. Open/adjust tickets and ownership based on findings.
