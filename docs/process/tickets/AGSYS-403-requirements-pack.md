# AGSYS-403: Selection Layer (Checkbox Logic) - Requirements Pack

## Overview
Implement the default selection logic for `TaskPackage` proposals. Every item (`Epic`, `Story`, `Task`) generated by the PM Orchestrator must be added to the `selectedItems` list by default.

## Pipeline Context
- **Pipeline:** `new-feature`
- **Stage:** `intake`
- **Owner:** `PM Orchestrator`
- **Ticket:** `AGSYS-403`

## Requirements
1. **Default Selection Rule:**
   - Any new `TaskPackage` instance must initialize `selectedItems` with the IDs of all objects in `epics`, `stories`, and `tasks`.
2. **User Overrides:**
   - The UI (or the user in chat) must be able to specify a subset of IDs to keep in `selectedItems`.
   - The PM must respect the *reduced* `selectedItems` list in the "Confirmation Step" (Task 12.4).
3. **Validation:**
   - Ensure `selectedItems` only contains IDs present in the package.

## Acceptance Criteria
- [ ] All proposed items are selected by default (`selectedItems = all.map(id)`).
- [ ] Logic for removing items from selection is defined.
- [ ] `TaskPackage` status transition from `draft` to `confirmed` requires a final list of `selectedItems`.

## User Approval Gate
User must confirm that they want *all* items selected by default rather than a manual selection start.
