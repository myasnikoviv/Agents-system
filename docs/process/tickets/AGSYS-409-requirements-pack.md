# Requirements Pack: AGSYS-409 (Verification Contract)

## Objective
Establish a formal contract for autonomous task verification to ensure that "Done" means "Verified".

## Acceptable Criteria
1. Define `VerificationReport` model in `src/runtime/pm/models/pm-types.ts`.
2. Includes `status`: 'passed' | 'failed' | 'manual_review_required'.
3. Includes `evidence`: array of links to files/logs (e.g., `docs/process/tests/<taskId>.md`).
4. Includes `validator`: slug of the agent role (e.g., `tdd-qa`).
5. Includes `autoRetryCount`: tracking how many times this task has been sent back.

## Verification
- Model compiles and is imported by `RunContext`.
- Mock verification report can be generated by a test script.
