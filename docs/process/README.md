# Process Artifacts

This directory stores pipeline evidence.

Canonical entrypoint: `/Users/myasnikoviv/development/trade_bot/docs/process/INDEX.md`

- `tickets/` product tickets
- `designs/` technical designs and architecture notes
- `tests/` test plans and reports
- `runs/` backtest and experiment reports
- `reviews/` code review findings
- `releases/` release and incident notes
- `retrospectives/` post-task reflection reports
- `skills/` skill create/update proposals
- `instructions/` instruction evolution proposals
- `ops/` infrastructure inventory, drift, and incident playbooks
- `pm/` sprint efficiency and team execution registers
- `git/` worktree policy and assignment registry
- `git/` also stores wrong-branch/conflict recovery artifacts and templates
