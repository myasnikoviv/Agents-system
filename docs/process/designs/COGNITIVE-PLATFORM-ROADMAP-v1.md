# Cognitive Multi-Agent Platform Roadmap v1

## Scope
Implements core requirements from agent evolution specification.

## Phase 1 Foundation
1. Agent/pipeline audit and registry refresh
2. Skill schema formalization (`docs/skills/skill-schema-v2.md`)
3. Knowledge schema formalization (`docs/knowledge/schema.md`)
4. Retrospective schema (`docs/process/retrospectives/RETRO-REPORT-SCHEMA-v1.md`)
5. Add Research Agent and Knowledge Curator
6. Upgrade PM role to Supervisor mode

## Phase 2 Cognitive Upgrade
1. Unified intake pipeline with full/lightweight modes
2. Reflection stage standardization
3. Knowledge update obligations
4. Skill gap detection routing
5. Instruction update proposal flow

## Phase 3 Self-Improvement
1. Automated proposal generation hooks (future)
2. Proposal review and approval workflow hardening
3. Knowledge-driven execution checks in runtime process

## Phase 4 Tooling / MCP
1. Repo/file integration
2. Docs/context integration
3. Task-board integration
4. Test/backtest execution integrations
5. Observability, performance, cost telemetry

## Done Criteria Mapping
- Complex tasks cannot skip research/planning gates
- Lessons learned are captured as reusable artifacts
- Skills are structured and lifecycle-managed
- Instruction evolution is traceable and reviewable
