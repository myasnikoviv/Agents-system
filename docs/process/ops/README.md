# Ops Artifacts

Canonical infrastructure artifacts owned by DevOps Engineer.

- `machine-profile.md` local host and runtime profile
- `runtime-inventory.md` services/containers/ports/health inventory
- `dependency-baseline.md` pinned baseline versions and drift policy
- `incident-playbook.md` infra incident response runbook
- `cockpit-operator-runbook.md` cockpit operations and approval-flow playbook
- `white-label-onboarding-runbook.md` project onboarding flow for portable cockpit runtime
- `postgres-migrations-runbook.md` canonical Postgres migration flow for Cockpit storage tables
