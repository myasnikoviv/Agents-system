# Infrastructure Incident Playbook (Template)

## 1. Triage
- Reproduce
- Scope impact
- Capture logs and status

## 2. Diagnose
- Container health
- Env key validation
- Port conflicts
- Network/storage checks

## 3. Mitigate
- Fast rollback path
- Service restart order
- Minimal hotfix

## 4. Verify
- UI/API reachability
- Health checks green
- Core workflows pass

## 5. Postmortem
- Root cause
- Permanent fix
- Preventive action tickets
- Template: `docs/process/ops/postmortem-template-agsys-3868.md`
