# Internal Skill Schema (Trade Bot)

## Required metadata (frontmatter)
- `id`
- `version`
- `status`
- `owner_roles`
- `category`
- `adoption`
- `source_references`
- `updated_at`

## Required sections
1. `name`
2. `description`
3. `when_to_use`
4. `when_not_to_use`
5. `inputs`
6. `outputs`
7. `required_tools`
8. `workflow`
9. `validation_checklist`
10. `common_failures`
11. `examples`
12. `related_skills`
13. `project_specific_notes`

## Quality rules
- Workflow must be actionable and step-based.
- Validation checklist must contain functional + behavioral checks.
- Examples must include at least one realistic project scenario.
- Skill text must avoid vendor-specific assumptions unless declared in `project_specific_notes`.
